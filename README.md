# sistema_de_estoque
Sistema simples de Controle e Armazenamento de Estoque.

O Sistema traz um modelo simplificado de gerenciamento de estoque, com menu e também opções de funcionalidades específicas do programa para o usuário utilizar de acordo com a sua necessidade.

Conceito de funcionalidade: Listar produtos, verificar quantidades e preço unitário do produto.

Exemplo de nomes de produtos:
Arroz, Feijão e Óleo

# Instruções
1 - Executar o script em um Terminal.

2 - O Sistema informa as opções para o usuário

3 - O usuário digita um número referente as opções listadas

4 - E para encerrar o sistema o usuário digita o número referente de saída

# Funcionalidades
1 - Visualizar o Estoque Atual

2 - Adicionar Produto

3 - Registrar Saída de Produto

4 - Sair do Sistema

# Requisitos
# Ambiente:
Ter o Python instalado.

# Ferramenta:
Executar via Terminal (CMD ou PowerShell).
